# Mandela Cup — таблица, которая обновляется сама

Лига публичная, логин Yahoo не нужен. `scrape.py` забирает итоги матчапов и пересобирает `index.html`.

Кнопка на самой странице Yahoo дёрнуть не может: браузеру запрещён чужой сайт. Поэтому «нажатие» — это кнопка **Run workflow** в GitHub, а ежедневное обновление делает расписание.

## Один раз

1. Заведи пустой репозиторий на GitHub и залей туда эту папку (`scrape.py`, `.github/workflows/refresh.yml`, этот README).
2. Settings → Pages → Branch: `main`, folder: `/ (root)` → Save. Через минуту страница будет на `https://<ты>.github.io/<репозиторий>/`.
3. Actions → Refresh Mandela table → **Run workflow**. Это и есть ручное обновление. Первый прогон снимет недели с 1-й по текущую.
4. Готово. Дальше каждый день в 13:00 по Праге экшен сам переснимет текущую неделю и предыдущую (на случай корректировок). Прошлые недели остаются в `data.json`.

## Свой компьютер

```bash
python scrape.py
```

Открой получившийся `index.html`. Зависимостей нет, нужен только Python 3.

## Что обновляется

- Текущая неделя — каждый запуск, пока матчап ещё идёт.
- Прошлая неделя — тоже, чтобы поймать stat corrections.
- Более старые — только если их ещё нет в `data.json`.
