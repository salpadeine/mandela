# Nelson Mandela Cup

Таблица категорий за неделю по лиге Nelson Mandela Cup.

Сверху можно смотреть сумму за сезон или отдельную неделю. Чем зеленее ячейка, тем лучше результат среди лиги. У GAA наоборот: зеленее тот, у кого меньше. В сезоне GAA — среднее по неделям, остальные цифры складываются.

Внизу можно сравнить любые две команды по тем же категориям или подставить соперника этой недели.

Пока неделя идёт, таблица показывает текущий срез. После окончания недели цифры остаются как итог, а сверху появляется следующая неделя. Обновление само, раз в день.
